    Official description

    Rutta is an AI-powered keyboard and companion app designed to make typing faster and clearer.
    With Rutta, you can use voice input, rewrite text in different tones, manage your personal dictionary, and switch between supported languages. The app includes account sign-in, keyboard settings, language preferences, and tools to help personalize your typing experience.

    Key features:
    - Voice input for faster text entry
    - AI rewriting options for clearer expression
    -Personal dictionary management
    - Multilingual keyboard support
    - Custom keyboard and language settings
    - Privacy-focused controls for history and saved data

    Rutta is built for users who want a smarter, faster, and more flexible typing experience across everyday apps.
