    erp.li - Universal Odoo Client
    ===============================

    The ultimate mobile client for Odoo ERP systems. Access any Odoo instance from your Android device with a modern, feature-rich interface designed for productivity on the go.

    🚀 KEY FEATURES

    Universal Compatibility
    - Works with ANY Odoo instance (Community & Enterprise)
    - Supports Odoo 14, 15, 16, 17, and 18
    - Compatible with self-hosted and cloud-hosted installations
    - Custom domain support with flexible database configuration

    Multi-Account Management
    - Switch seamlessly between multiple Odoo accounts
    - Save credentials securely for quick access
    - Manage personal and business accounts separately
    - Remember your last active session

    Smart Push Notifications
    - Real-time notifications for important updates
    - Supports both ntfy (self-hosted) and Firebase Cloud Messaging
    - Activity reminders and task alerts
    - Email notifications and message updates
    - Automatic notification configuration based on your server

    Professional Features
    - Full-screen web interface with native performance
    - Custom database name support for complex deployments
    - Secure session management with auto-login
    - Bilingual interface (English & Arabic)
    - Optimized for tablets and phones

    File Management
    - Download reports, invoices, and documents
    - Automatic file storage in your Downloads folder
    - View PDFs, Excel files, and images directly
    - Share files with other apps

    Security & Privacy
    - Encrypted credential storage
    - Session-based authentication
    - Secure HTTPS connections
    - No data collection or tracking
    - Privacy-first design

    📊 PERFECT FOR

    - Business Owners managing their company on the go
    - Sales Teams accessing CRM and quotations
    - Warehouse Staff checking inventory and shipments
    - Accountants reviewing invoices and payments
    - Project Managers tracking tasks and timelines
    - Field Service Teams updating work orders
    - IT Administrators managing multiple Odoo instances

    🎯 WHY CHOOSE ERP.LI?

    Unlike other Odoo clients that only work with specific hosting providers, erp.li is truly universal. Connect to your self-hosted server, use it with any Odoo SaaS provider, or access Odoo.com instances - it just works.

    Our multi-account system means you can manage your personal business, client accounts, and work instances all from one app. No need to log in and out constantly.

    Smart notification support ensures you never miss important updates. The app automatically detects your server's notification capabilities and configures itself accordingly - no manual setup required.

    🌐 LANGUAGE SUPPORT

    - English (Full support)
    - Arabic (Full support with RTL)
    - More languages coming soon

    ⚙️ TECHNICAL SPECS

    - Minimum Android version: 8.0 (API 26)
    - Recommended: Android 10+ for best experience
    - Size: ~50 MB
    - Permissions: Internet, Notifications, Storage (for downloads)
    - No ads, no trackers, no analytics
